# Infinity ∞ — THE ENGINEER

منصة الأخبار والمقارنات، منشورة كصفحة ويب حية تُحدَّث تلقائيًا.

- **الموقع:** https://engraymanfm-oss.github.io/infinity-platform/
- **الكود:** https://github.com/engraymanfm-oss/infinity-platform

## كيف تعمل

| الجزء | الوصف |
| --- | --- |
| `index.html` | المنصة كاملة في ملف واحد (v8): الأخبار، المقارنات، الأقسام، المساعد ∞، ومواجهة الذكاء. |
| `assets/` | الشعارات الرسمية مقصوصة من ورقة الهوية: `logo-circle-dark` (الدائري النيون)، `logo-circle-light`، و`logo-vertical` — PNG + WebP. |
| `scripts/update_news.py` | يجلب خلاصات RSS من الخادم (بلا وسطاء CORS)، يكمل الصور الناقصة من `og:image`، ويكتب `CURATED` و`SNAPSHOT` و`CURATED_AT` داخل `index.html`. |
| `.github/workflows/update-news.yml` | يشغّل السكربت كل 4 ساعات وعند الطلب، ثم يرفع التغيير ويعيد بناء الصفحة. |
| `android/` | تطبيق أندرويد خفيف (WebView) باسم Infinity يفتح الموقع الحي. |
| `.github/workflows/build-apk.yml` | يبني الـAPK وينشره في Release باسم `v1.0` (ملف `Infinity.apk`). |

## ما في نسخة v8

- **هوية `The ∞ Engineer` فقط:** الألوان الثمانية الرسمية + الأبيض، والشعار الدائري والعمودي من ورقة الهوية (بلا إطار أسود حول الدائرة)، وخلفية مخطط هندسي نابضة تتفاعل مع المؤشر.
- **الرئيسية:** شريط «اليوم في لمحة» بعدّادات متحركة، عدّاد مباراة برشلونة القادمة، «إيجاز 30 ثانية»، خط زمني أفقي «المرتقب قريباً» (أفلام + أنمي)، «أحدث ما وصل»، وشرائح الأقسام.
- **بطاقات ذكية:** شارة مزاج (`عاجل` · `تقني` · `إيجابي` · `اقتصاد`)، زر حفظ، ورقة تفاصيل (Bottom Sheet على الجوال / Modal على المكتبي) فيها «الزبدة في 3 نقاط» وشريط أهمية وزر «زيارة الموقع».
- **محفوظاتي:** تبويب `#/saved` مبني على `localStorage` مع نجمة حفظ على بطاقات الأخبار والبرامج والأنمي والأفلام.
- **مواجهة الذكاء:** «المختار الذكي» ثلاث خطوات (هدف → ميزانية → أفضل 3 بالتوافق) فوق المُقارن والرادار ومصفوفة المواجهة.
- **مساعد ∞:** زر دائري بالشعار الدائري يفتح بحثًا فوريًا + 3 مقترحات سياقية حسب الصفحة + إدخال صوتي عربي (`ar-SA`) مع بديل كتابي.
- **تراكمي:** الأنمي والأفلام والبرامج تُدمج ولا يُحذف قديمها — في الواجهة (`localStorage` أرشيف) وفي المشغّل (`CUMULATIVE_KEYS`).

## الأوامر

```bash
# تحديث الأخبار يدويًا من جهازك
python3 scripts/update_news.py

# تشغيل مشغّل التحديث على GitHub
gh workflow run update-news.yml --repo engraymanfm-oss/infinity-platform

# بناء الـAPK
gh workflow run build-apk.yml --repo engraymanfm-oss/infinity-platform
```

## قواعد ثابتة

- لا يُحذف أو يُعاد ترتيب أي قسم قائم، بما فيه تصنيف +18.
- الأقسام المحرّرة يدويًا (`barca`، `selfdev`) لا يلمسها المشغّل.
- المشغّل يحدّث فقط المفاتيح التي لها خلاصة في `FEEDS` وموجودة أصلًا في الصفحة، ويرفض العمل إذا غابت علامات v8 من `index.html`.
