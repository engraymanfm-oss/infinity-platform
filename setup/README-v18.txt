ملفات GitHub Actions لا تُدفع من هذا الحساب لأن تطبيق GitHub المربوط لا يملك صلاحية
«workflows». الصق محتوى أي ملف من هنا في .github/workflows/ بنفس الاسم من واجهة
GitHub (Add file → Create new file) أو امنح التطبيق صلاحية Workflows.

- update-news.workflow.yml  → .github/workflows/update-news.yml   (تحديث الأخبار كل 4 ساعات)
- build-apk.workflow.yml    → .github/workflows/build-apk.yml     (آخر نسخة تعمل من الـAPK v2.2)
